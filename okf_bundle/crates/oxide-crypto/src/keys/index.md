# keys

## Classs

- [AeadKey](AeadKey.md) — AEAD encryption key (ChaCha20-Poly1305 or AES-GCM)

- [KeyFingerprint](KeyFingerprint.md) — Key fingerprint (Blake3 hash of public key)

- [SharedSecret](SharedSecret.md) — Shared secret from Diffie-Hellman
